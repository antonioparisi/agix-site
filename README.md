# Agix website

The site for [Agix](https://antonioparisi.github.io/agix-site/): crews of coding agents on Claude Code, Codex and Pi, on your own machine.

A static page (`index.html`, `styles.css`, `app.js`) served by GitHub Pages from this branch. The clips in `media/` are recorded from the real Mission control running on demo data; nothing in them comes from a real project.
